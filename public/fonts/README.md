# Fonts

Self-hosted subsets of two Google Fonts families, both licensed under the
SIL Open Font License 1.1 (https://openfontlicense.org).

| File | Family | Subset | Axes |
| --- | --- | --- | --- |
| `bricolage-grotesque-latin.woff2` | Bricolage Grotesque | latin | opsz 12–96, wght 200–800 |
| `bricolage-grotesque-latin-ext.woff2` | Bricolage Grotesque | latin-ext (includes ₾) | opsz 12–96, wght 200–800 |
| `noto-sans-georgian.woff2` | Noto Sans Georgian | georgian (Mkhedruli + Mtavruli) | wght 100–900 |

The `@font-face` rules with matching `unicode-range` live in `app/globals.css`.
